# Security Policy

## Supported Versions

Only the latest published version of SuperbString is actively supported with security fixes.

## Reporting a Vulnerability

Please use responsible disclosure.

- For non-sensitive security issues, open a GitHub issue: https://github.com/sharjeelfaiq/superbstring/issues
- For sensitive reports, contact the repository owner directly through the contact information available on the GitHub profile: https://github.com/sharjeelfaiq

Please include:

- A clear description of the issue.
- Steps to reproduce, if possible.
- Affected version or commit.
- Any known workaround.

## Response Expectations

- Acknowledgement target: within 7 days.
- Initial investigation target: within 14 days.
- Resolution target: based on severity and complexity, with critical issues prioritized.

Security fixes will be handled with the least disruptive change possible and will preserve backward compatibility when practical.
