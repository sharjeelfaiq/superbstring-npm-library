# Code of Conduct

## Purpose

SuperbString is a small open-source npm package for JavaScript and TypeScript string utilities. This Code of Conduct helps keep the project welcoming, respectful, and productive for maintainers, contributors, and users.

## Expected Behavior

Participants are expected to:

- Be respectful and considerate in discussions.
- Give and receive feedback constructively.
- Keep issues and pull requests focused on the project.
- Assume good intent while still being clear about problems.
- Respect maintainers' time and project scope.

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment, intimidation, or discriminatory language.
- Personal attacks, insults, or trolling.
- Publishing private information without permission.
- Repeated off-topic or disruptive comments.
- Any conduct that would reasonably make participation unsafe or unwelcome.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying expected behavior and may remove, edit, or reject comments, issues, pull requests, or other contributions that do not follow this Code of Conduct.

Maintainers may also temporarily or permanently limit participation when behavior is harmful to the project or community.

## Reporting Process

To report a concern:

- For public, non-sensitive concerns, open an issue: https://github.com/sharjeelfaiq/superbstring/issues
- For sensitive concerns, contact the maintainer through the GitHub profile: https://github.com/sharjeelfaiq

Reports should include relevant context, links, screenshots, or examples when possible. Maintainers will review reports in good faith and respond as appropriate for the situation.

## Scope

This Code of Conduct applies in all project spaces, including GitHub issues, pull requests, discussions, documentation, and any other public communication related to SuperbString.
